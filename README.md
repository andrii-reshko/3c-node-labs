## Вимоги до середовища розробки

- Node.js – версія ^24.0 (поточна LTS версія)
- npm – версія ^11.0


## Запуск програми

Клонувати репозиторій та перейти до відповідної гілки з лабораторною роботою:
```shell
git clone git@github.com:andrii-reshko/3c-node-labs.git
cd 3c-node-labs
git checkout lab_1
```

Налаштувати змінні середовища (відредагуйте .env файл, якщо потрібно)
```shell
cp .env.example .env
```

Запустити програму
```shell
npm run serve
```
